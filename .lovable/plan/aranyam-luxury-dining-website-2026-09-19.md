# Aranyam Luxury Dining Website

## Build
- Replace the blank home screen with an immersive black-and-gold restaurant experience for vegetarian and non-vegetarian fine dining.
- Create a cinematic opening sequence with a graceful skip control, then reveal the full site with restrained motion.
- Use original, realistic food and interior imagery generated specifically for the page.
- Add a transparent-to-solid navigation bar, full-screen opening scene, signature dishes, chef story, dining atmosphere, testimonials, reservation form, and concise footer.
- Make dish categories interactive and make reservation submission provide clear confirmation.
- Add smooth scrolling, layered image movement, cursor-responsive depth, gentle perspective tilts, and refined hover details while respecting reduced-motion settings.
- Polish desktop, tablet, and mobile layouts and verify the complete visitor flow in the live preview.

## Visual direction
- Near-black lacquered surfaces, antique gold accents, warm ivory typography, and restrained botanical green and wine-red cues for veg/non-veg labels.
- Editorial serif display type paired with a clean humanist sans serif.
- Cinematic food photography, asymmetric compositions, fine rules, generous spacing, and mostly square corners.
- Motion stays slow and tactile rather than flashy; depth comes from photography, light, perspective, and layered movement.

## Technical details
- Keep the experience on the existing TanStack Start home route with route-specific social metadata.
- Extend the global semantic token system for the palette, typography, depth, and animation values.
- Use generated local media assets, React state for interactions, CSS transforms and requestAnimationFrame-driven pointer depth where appropriate.
- Keep all controls keyboard accessible and include reduced-motion fallbacks.
